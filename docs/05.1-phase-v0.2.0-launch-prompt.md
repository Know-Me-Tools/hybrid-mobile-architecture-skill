## Architectural commitments (binding — do not re-litigate)

1. **Tauri = desktop only.** Mobile is **Flutter + Rust over FFI**
   via `flutter_rust_bridge`. Tauri 2.0 mobile is **not** a path.
2. **Substrate = in-process library + `--detach` mode.**
3. **Skill router = in-house**, SurrealDB embedded for vectors
   (not sqlite-vec).
4. **Plugin sandbox deferred to Pillar 6.** Ship the Pillar 5
   surface without a sandbox.
5. **HMA = git-installable.** `marketplace.json` + `plugin.json`
   at the repo root; the companion uses `git clone` + `git pull
   --ff-only` to install / upgrade.
6. **No Capacitor, ever.** Web-wrappers add a web layer and latency
   for no architectural benefit.
